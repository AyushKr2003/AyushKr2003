01 · media · android

                  
Musixir

                  

                    A music streaming app with background playback. Uploaders pick a thumbnail, an audio file and a colour, and that colour
                    themes the player and the mini-player. It runs on my own FastAPI service with JWT auth, uploads and favourites.
                  

                  
  • Flutter
  • Riverpod
  • just_audio
  • FastAPI

                  

                    
                    source ↗
                  

                

                

                  
02 · voice assistant · android + ios

                  
CognitoAI

                  

                    A voice assistant. Tap the mic and talk: speech_to_text writes it down, then GPT-3.5 decides whether you asked for a
                    picture. Questions go to ChatGPT and the answer is read back with flutter_tts. Picture requests go to DALL·E.
                  

                  
  • Flutter
  • speech_to_text
  • flutter_tts
  • OpenAI API

                  

                    source ↗
                  

                

                

                  
03 · AI search · web

                  
SageSearch

                  

                    Ask a question and a FastAPI backend searches the live web through Tavily, ranks the sources with sentence-transformers,
                    and streams a cited Gemini answer over a WebSocket into a Flutter web client.
                  

                  
  • Flutter
  • FastAPI
  • Gemini
  • Tavily
  • WebSocket

                  

                    
                    source ↗
                  

                

                

                  
04 · web3 · team project · web

                  
NexVote

                  

                    A voting app where every ballot is an Ethereum transaction. Voters connect a MetaMask wallet, browse elections and vote.
                    The client calls castVote on a Solidity contract through web3dart and reads the results back from the chain. I built the Flutter app.
                  

                  
  • Flutter Web
  • web3dart
  • Solidity
  • Node.js
